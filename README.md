# 🚀 AffiliWrite AI (BlogGen)

> **네이버 블로그 홈판 피드 & 스마트블록 상위노출 최적화 멀티 플랫폼 AI 콘텐츠 자동 생성기**

AffiliWrite AI는 제휴 마케팅 기획자, 전문 블로거, 콘텐츠 크리에이터를 위한 AI 원고 생성 및 트렌드 디스커버리 플랫폼입니다.
단 한 번의 원문/키워드 입력으로 2026년 최신 네이버 D.I.A.+, 스마트블록, 홈피드 추천 알고리즘을 완벽하게 만족하는 고품질 원고와 숏폼(Shorts, Reels, TikTok), 인스타그램, 애드센스 승인용 MDX 원고를 즉시 생성합니다.

---

## ✨ 핵심 기능

1. **🎯 황금 키워드 발굴기 (기회지수 분석 매트릭스)**:
   - **기회지수($\frac{\text{총 검색량}}{\text{블로그 문서수}}$)** 기반 블루오션 키워드 실시간 발굴.
   - **3대 발굴 모드**: 실시간 핫이슈 트렌드 발굴, 시드 키워드 연관 롱테일 확장, 대량 키워드 직접 입력 일괄 분석.
   - **황금 등급 배지**: 👑 초특급 황금(≥500), 🔥 우수 기회(≥100), ⚡ 양호(≥30), 📊 경쟁 치열.
   - **원스톱 원고 작성 연동**: 기회지수 높은 꿀키워드 클릭 한 번으로 `[원고 생성기]`에 제목/주제 자동 전달.
   - **편의 기능**: 엑셀(CSV) 다운로드, 키워드 전체 복사, 실시간 검색/문서수 필터 및 정렬.
2. **📊 네이버 데이터랩(DataLab) 인기 검색어 TOP 1~5위 실시간 수집**:
   - 네이버 데이터랩 쇼핑인사이트 실시간 1위~5위 인기 키워드 자동 추출.
   - 키워드별 스마트블록 최상위 인기글 크롤링 ➡️ 클린 필터링 ➡️ 원클릭 에디터 자동 주입.
   - 트렌드 피드 `📊 데이터랩순` 정렬 및 순위별 배지 지원.
3. **🏆 2026 네이버 홈판 피드 & 스마트블록 큐레이션 최적화**:
   - **0.9초 룰 & 초반 3초 이탈 방어**: 서두 최상단에 `[📌 3줄 핵심 요약 브리핑]` 박스 강제 배치.
   - **스마트블록 의도 역추적**: 독자의 4대 질문(기능, 가격/가성비, 장단점, 주의사항) 기반 H2 질문형 소제목 설계.
   - **구체적 수치/상황 표현화**: '좋아요/추천해요' 대신 구체적 스펙(데시벨, 배터리 지속시간, 무게, 금액) 자동 구체화.
   - **스마트에디터 ONE 원클릭 복사**: 3줄 요약 박스, 마크다운 비교 표(Table), 두괄식 FAQ가 깨짐 없이 깔끔한 네이버 공식 템플릿 스타일로 자동 클립보드 복사.
4. **📈 실시간 트렌드 & 카테고리 인기글 디스커버리 Feed**:
   - 네이버 공식 4대 대분류 및 31개 중분류 카테고리별 실시간 최상위 트래픽 글 자동 수집 및 클린 필터링.
5. **🔮 Gemini Nano Banana 2 영문 서술형 이미지 프롬프트 생성**:
   - 사진 구도, 피사체, 조명, 색감, 와이드 비율, 무텍스트 규칙을 완벽 준수한 고화질 썸네일/본문 이미지 프롬프트 자동 생성.
6. **🛡️ 100% 무료 플랜(Free Tier) 다단계 자동 폴백 체인**:
   - API 부하나 Rate Limit 발생 시 `gemini-3.6-flash` ➡️ `gemini-3.5-flash` ➡️ `gemini-3.5-flash-lite` ➡️ `gemini-2.5-flash` 순으로 무중단 자동 전환.

## 📈 네이버 홈피드 노출 극대화 운영 가이드 (2026)

생성기가 아무리 좋은 원고를 뽑아도 발행·운영 전략이 받쳐주지 못하면 홈피드 추천이 끊깁니다. 아래 원칙을 함께 지키세요.

### 1. 발행 타이밍 - 초반 반응률이 재추천을 결정한다
- 홈피드 알고리즘은 발행 후 1~2시간 내 반응(공감·댓글·체류)을 보고 확산 여부를 판단합니다.
- 권장 발행 시간대: 평일 저녁 19:00~22:00, 주말 오전 10:00~12:00 (네이버 트래픽 피크 직전)
- 새벽·출근 시간대 발행은 반응을 못 받아 묻히므로 피하세요.

### 2. 카테고리·태그 일관성 - 관심사 매칭의 기본
- 홈피드는 '사용자 관심 카테고리와 글의 카테고리' 매칭으로 노출합니다.
- 하나의 블로그는 주제군 1~3개로 일관 유지하고, 글마다 생성된 해시태그 5개를 그대로 등록하세요.

### 3. 첫 24시간 내 이웃 상호작용
- 발행 직후 이웃 소식에 먼저 공감·댓글을 남기면 역방향 유입과 초기 반응이 붙습니다.
- 매 글 결미의 소통 질문 CTA에 실제 답변을 다는 것이 다음 글의 초기 노출을 끌어올립니다.

### 4. 스마트블록 검색 유입 병행
- 홈피드(추천 트래픽)와 스마트블록/검색(탐색 트래픽)은 별개 엔진입니다.
- 질문형 H2와 FAQ가 스마트블록 인용 후보로 잡히므로, 제목·본문 키워드 밀도 가이드(메인 5~8회)를 준수한 원고를 사용하세요.

### 5. 저품질 방지 수칙
- 동일 문구 CTA·동일 제목 패턴 반복 금지 (생성기가 이미 5종 CTA 변형·제목 3각도를 지원)
- 가짜 통계·허위 경험담 금지 (페르소나 기능은 실제 경험 기반으로만 사용)
- 하루 3편 이상 연속 발행은 신규 계정에서 스팸 신호로 작용할 수 있으니 간격을 두고 발행하세요.
